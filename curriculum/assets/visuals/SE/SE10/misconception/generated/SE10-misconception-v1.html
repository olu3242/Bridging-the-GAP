Databases

Text equivalent and source

Correctly reject this misconception: Checking for duplicates in the interface is equivalent to a database constraint. An enrollment table references learner and course IDs and has a unique learner/course pair. Two concurrent enrollment requests then cannot create duplicate enrollment records even if both passed an earlier UI check. Enforce uniqueness in the database; two requests can both pass an earlier UI check.
